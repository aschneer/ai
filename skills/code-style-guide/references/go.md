# Go

- Follow [Effective Go](https://golang.org/doc/effective_go.html) and [Uber Style Guide](https://github.com/uber-go/guide/blob/master/style.md)
- Use `camelCase` for variables and functions
- Use `PascalCase` for exported names
- Use `UPPER_CASE` for constants
- Keep interfaces small (1-3 methods)
- Return errors as the last return value
- Handle errors explicitly, never use `_` to ignore them
- Use `gofmt` and `goimports` for formatting
- 1 tab for indentation
- 120 character line length limit
