# Code Smells to Avoid

Watch for these warning signs in code:

- **Long functions** - Functions doing multiple things or with many responsibilities
- **Long parameter lists** - More than 4 parameters (group related ones into objects)
- **Repeated code** - Same or similar logic in multiple places
- **Deep nesting** - More than 3 levels of indentation
- **Complex conditionals** - Long boolean expressions that are hard to understand
- **Commented code blocks** - If code needs a comment to explain "what", extract to function
- **Generic names** - `data`, `temp`, `value`, `result`, `process()`
- **Magic numbers** - Unnamed constants scattered through code
- **Large classes** - Classes with many methods or responsibilities
- **Inconsistent naming** - Mixed conventions within same codebase
