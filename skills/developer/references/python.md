# Python

- Follow [Google Python Style Guide](https://google.github.io/styleguide/pyguide.html)
- Use type hints for all function signatures and public APIs
- Maximum line length: 88 characters (Black formatter default)
- Use 4 spaces for indentation
- Use `snake_case` for variables, functions, and methods
- Use `PascalCase` for classes
- Use `UPPER_CASE` for constants
- Use double quotes for strings (enforced by Black)
- Always use f-strings for string formatting
- Use `isinstance()` instead of `type() ==` for type checking
- Prefer list/dict/set comprehensions over loops when they improve readability
- Use `pathlib` instead of `os.path` for file system operations
